## Two findings in the document, neither edited

The brief is explicit that **Jon supplies the file**, so nothing in it was
changed. Both of these are for v3.3.8.

### 1. The chart line styles are inverted — and this is the third time

§1 reads:

> baseline **dashed** / adjusted **solid** per cell

**It is the other way round.** As built at `a766d0b`:

```tsx
dataKey={measureKey(kpi, activeMeasure, 'Baseline')}
stroke={c.baseline} strokeWidth={2}            // no dasharray → SOLID
…
dataKey={measureKey(kpi, activeMeasure, 'Adjusted')}
stroke={c.adjusted} strokeWidth={2}
strokeDasharray="5 5"                          // WhatIfTab.tsx:4224 → DASHED
```

The on-screen key agrees — a solid swatch beside *Baseline (Step 1)*, a dashed
one beside *Adjusted (+ Events)*.

**Why it matters more than a typo.** This same inversion was in the 1005
user-guide brief, was caught by reading the source, and was reported as the
headline finding of that session — the guide documents what is built precisely
because following the brief would have taught every reader to misread every
chart. It has now travelled from a brief into **the document each advisor chat
reads before its first turn**, where it will seed the next brief that mentions
the chart.

The document's own preamble names this failure mode two sentences before it
happens:

> a condensation once dropped "barred class" from D5 and inverted its meaning,
> costing a wrong brief … **A prior report's claim is a premise for the next
> brief, not a fact.**

The 1005 report's Repo line is `3c0dcb2` and its FOR ADVISOR block leads with
the correction. §5 records that report as **"RAN, REPORT NOT YET RECONCILED"**,
which is very likely how the inversion survived: the correction is in a report
nobody has read back yet.

*pre-sweep* locale key count, from the census table, not the denominator for
810. Today, after the follow-up added keys, German is **815 of 854**.

Immaterial to any decision; noted because §1's figures are quoted into briefs.
