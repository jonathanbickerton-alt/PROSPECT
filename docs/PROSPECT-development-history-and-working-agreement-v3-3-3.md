## 1. What PROSPECT is

PROSPECT (Predictive Reporting Of Scenarios & Planned Execution for Commercial Trends) is a React/TypeScript subscriber forecasting application for Vodafone, built entirely through Claude Code — Jon directs, writes no application code himself. Rebuilt around real IBRO data (Inflow, Base, Retention, Outflow).

- Three-step workflow via ForecastContext: Baseline Forecast → Market Events → Actuals Review; plus **Scenario Compare** (loads up to 4 exported session files; own parser feeding `computeScenarioForFilter`; now partially on the shared seams — see §3). Step 2/3 unlock derives from store contents. Top-nav: **Overall Forecast**.
- Models: SES, Holt Linear, Damped Trend, true Holt-Winters. Scoring: symmetric absolute percentage deviation + band position.
- **Base volume is never fitted or stored per month** — reconstructed at read time from the seed rolled through flows; `seedBaseKnown` gates; unknown seed declines the series.
- Dimensions: Customer Segment + Product/Channel/Tariff L1/L2; 7-part keys via makeForecastKey. ScopeDims: 'All'/null/undefined all wildcards; a literal 'All' can never come from a data row, but a literal 'All' in a recorded scope (Active_Cohort metadata, event sheet rows) is the wildcard, kept verbatim.
- **Event carriers — THREE**: `MarketEvent` (Volume + Promotion cards, `isPromotion`; only carrier with `campaignName`), `YieldEvent` (Value card; `rollForward`; no productL2/tariff dims), `PricingEvent` (Pricing card; `duration`). **Cross-carrier application order is a FIXED PIPELINE BY KIND**: market → yield → pricing, month within; cross-carrier creation order does not exist.
- **Each carrier now has real reader AND writer seams** (2026-08-19): `marketEventFromRow(r, source)` / `marketEventExportRow`, `yieldEventFromRow` / `yieldEventExportRow`, `pricingEventFromRow` / `pricingEventExportRow`. The market reader takes a **source argument** ('workbook' | 'session') because the two historical inline parses NEVER matched (minted vs restored ids, `||` vs `??`, forced-negative Outflow) — each correct for its input; the divergence now lives in one declared place. **An exporter writes a placeholder Note sheet for an empty carrier** (header exactly ['Note']); the shared placeholder guard skips it before any fromRow seam — a skipped placeholder yields an EMPTY event array, never phantom events (2026-08-20).
- **The pricing card's three surfaces, three honest jobs**: Preview describes the live draft (event-scoped, memoised); the row is the event's SAVE-TIME RECORD (stored baseline + stored weighting volumes, one slice at one moment); the chart carries current truth. 
- Business users: Alessandro Russo and Marcel Wiegand. In testing, not yet UAT. **UAT bar: R7, then the DQ import phase.**
- Roadmap: Cloud Run + BigQuery, AI Booster ML, four AI use cases; AISHA event schema. AI capability parked on ai-capability branch.
- Deployment: nginx serves the build; server.ts tracked; exclusion at `.dockerignore` (48–49).

## 4. Standing rules (mirrored in EXPECTED.md / agent definitions)

- Provenance: establish an artefact's commit against HEAD before reading a number from it.
- No figure for an unopened population. Surface-not-store; state-not-transition; mount above EVERY gate; gates derive from the store.
- **A spec may not feed itself the artefact under test**; expected values are hand-written literals. **A spec that mirrors the code under test certifies its own mirror** — ask what a trap would redden BEFORE trusting a green (2026-08-19); extract until the assertion is reachable.
- **A probe that MODELS the path inherits the modeller's assumptions — drive the real path.** Refusing a modelled probe and recording the limit open is the correct outcome when the real path is unreachable.
- **Running a spec is evidence for what it mounts, nothing wider.** An enumeration method is evidence about what it found, never what it missed.
- A spec guard is verified by a planted violation or not verified; plants where the heuristic is weakest; INCONCLUSIVE earns its keep. **Permanent negative controls pin EXACT counts.**
- Removal test authoritative when typecheck is green; untestable-in-place is itself the defect — extract the seam. **Third-instance rule:** load-bearing invariants are exercised at the site.
- JSON.stringify launders NaN to null; an exported 0 is not recoverable as absence; an absent pool is not an empty pool. **An exporter's empty-carrier placeholder is a SHAPE, not data — consumers guard for it once, at the shared boundary** (2026-08-20).
- Deployment "not needed" translates to a layer first. The 'All' marker-meaning family has FIVE sites; DQ closes them against one set.
- Duplicate predicates collapse on sight — one exported definition per concept.
- Reserved decisions stay reserved; sessions HOLD and present options. A decision conditional on a measurement carries the measurement's verdict — including a refutation.
- A harness noop needs a source-side count guard. Nullable-under-no-strict enumerates nothing.
- A check that doesn't mention what the function is FOR is not a check of it; traps are planted on FIXES.
- Convention beats the brief's phrasing.
- **A check that cannot fail is worse than an absent one**; style assertions pin state-unique tokens with a paired negative.
- **Anchors: duplication invalidates like rewrite — COUNTS, exact, never `>=`, re-aimed with sites named. No unclaimed properties (LF-normalised). Windows bounded STRUCTURALLY, never by character distance.** Multi-part mutations verify each part or split.
- **A summariser/projection describes, never re-derives.**
- **Measure before shipping a cost into a render path**; thresholds stated; the fallback pre-authorised; a failed measurement is the deliverable. Timing figures name their conditions.
- **A silent render failure is a defect independent of its cause** (2026-08-20): a region that can fail must be able to SAY so; a gate that checks non-emptiness does not check drawability; a boundary that swallows is its own finding.
