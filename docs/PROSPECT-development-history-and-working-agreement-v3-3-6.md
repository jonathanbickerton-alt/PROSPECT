## 1. What PROSPECT is

PROSPECT (Predictive Reporting Of Scenarios & Planned Execution for Commercial Trends) is a React/TypeScript subscriber forecasting application for Vodafone, built entirely through Claude Code — Jon directs, writes no application code himself. Rebuilt around real IBRO data (Inflow, Base, Retention, Outflow).

- Three-step workflow via ForecastContext: Baseline Forecast → Market Events → Actuals Review; plus **Scenario Compare** (up to 4 session files; own parser feeding `computeScenarioForFilter`; partially on the shared seams). Step 2/3 unlock derives from store contents. Top-nav: **Overall Forecast**.
- Models: SES, Holt Linear, Damped Trend, true Holt-Winters. Scoring: symmetric absolute percentage deviation + band position.
- **Base volume is never fitted or stored per month** — reconstructed at read time from the seed rolled through flows (`b = max(0, b + prevIn − prevOut)`); `seedBaseKnown` gates; unknown seed declines the series.
- Dimensions: Customer Segment + Product/Channel/Tariff L1/L2; 7-part keys via makeForecastKey. ScopeDims: 'All'/null/undefined all wildcards; a literal 'All' never comes from a data row but IS the wildcard in recorded scopes (Active_Cohort metadata, event sheet rows).
- **Event carriers — THREE**: `MarketEvent` (Volume + Promotion cards, `isPromotion`; only carrier with `campaignName`), `YieldEvent` (Value card; `rollForward`), `PricingEvent` (Pricing card; `duration`). **Pipeline order by kind**: market → yield → pricing, month within; cross-carrier creation order does not exist. All six reader/writer seams real and spec-driven (`marketEventFromRow(r, source)`; `yieldEventFromRow`; `pricingEventFromRow`; three exportRow twins). **A placeholder Note sheet (header exactly ['Note']) is a SHAPE, not data** — one shared guard skips it before every seam.
- **The pricing card's three surfaces**: Preview describes the draft (event-scoped, memoised); the row is the SAVE-TIME RECORD; the chart carries current truth. **Preview + row baselines are event-scoped through `resolveEventScopeForecast`; the CHART is a genuinely different named quantity — the loaded cohort under the view filter — and is CORRECT as it stands. Do not "fix" it.**
- **The volume card's churn mode (R7, SHIPPED)**: a third arm on the amount toggle (Subs / % / Churn), Outflow-only, exclusive tri-state derived not flagged; per-month deltas precomputed at save by a sequential fold; N events per ramp sharing campaignName; signed verbatim in STORAGE (D4); rendered as DIRECTION OF EFFECT in the Δ column (negated at one named display site — Jon's option-(a) decision); companions hidden. Ramps group-edit via a dedicated remove-and-restate branch; members decline row-edit pointing at the campaign route.
- Business users: Alessandro Russo and Marcel Wiegand. **UAT opens ~2026-09-01 on curated files (re-scoped — see §3); own-extract loading arrives mid-UAT with the DQ drop.** Native review of the guide's German (Marcel) and Italian (Alessandro) is a UAT-era ask.
- Roadmap: Cloud Run + BigQuery, AI Booster ML, four AI use cases; AISHA event schema. AI capability parked on ai-capability branch.
- Deployment: nginx serves the build; server.ts tracked; exclusion at `.dockerignore` (48–49).
