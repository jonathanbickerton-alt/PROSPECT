## 1. What PROSPECT is

PROSPECT (Predictive Reporting Of Scenarios & Planned Execution for Commercial Trends) is a React/TypeScript subscriber forecasting application for Vodafone, built entirely through Claude Code — Jon directs, writes no application code himself. It originated in Google AI Studio, migrated to Claude due to usage limits, and was rebuilt around real IBRO data (Inflow, Base, Retention, Outflow) after initially mocking segments.

- Three-step workflow sharing state via ForecastContext: Baseline Forecast → Market Events → Actuals Review; plus Scenario Compare (own parser, never gated). Step 2/3 unlock **derives from store contents**. The top-nav item is labelled **Overall Forecast**; Step 1 is reached from the step indicator.
- Forecasting models: SES, Holt Linear, Damped Trend, true Holt-Winters. Accuracy scoring: symmetric absolute percentage deviation, band position as secondary flag.
- **Base volume is never fitted or stored per month** — reconstructed at read time by rolling an opening stock (the seed) forward through forecast flows. Seed known-ness is explicit (`seedBaseKnown`); an unknown seed declines the series.
- Dimensions: Customer Segment + Product/Channel/Tariff L1/L2. 7-part keys via makeForecastKey. By ScopeDims convention 'All'/null/undefined are all wildcards, so a literal 'All' can never come from a data row — but a literal 'All' in a recorded SCOPE (e.g. the Active_Cohort metadata block) is the cohort's wildcard, kept verbatim; the distinction is stated in source and asserted.
- **Event carriers — THREE** (2026-08-14): `MarketEvent` (Volume AND Promotion cards, discriminated by `isPromotion`; sheet Market_Events; only carrier with `campaignName`), `YieldEvent` (Value/Yield card; `rollForward`; no productL2/tariff dims), `PricingEvent` (Pricing card; `duration`). Each has its own state array, export sheet, and list UI.
- **Cross-carrier application order is a FIXED PIPELINE BY KIND**: market → yield (pass 2) → pricing (pass 3), month within. Market `sequence` is display/edit-slot only; YieldEvent and PricingEvent carry no ordering field — cross-carrier creation order does not exist.
- **The pricing card's three surfaces, three honest jobs** (settled across the 2026-08-17/18 fix chain): **Preview** describes the live draft (event-scoped, memoised on dims+month); the **row** is the event's SAVE-TIME RECORD (stored baseline AND stored weighting volumes, one slice at one moment); the **chart** carries current truth (the one apply path). Preview/row divergence is legitimate only when data changed between save and viewing.
- Business users: Alessandro Russo and Marcel Wiegand. In testing, not yet UAT. UAT bar: Phase 3 (done), its walk (done), the R4/R5 arc (done), and the DQ import phase.
- Roadmap: Cloud Run + BigQuery, AI Booster ML, four AI use cases; AISHA closing the Actuals→Events loop via a strict event schema. AI capability parked on ai-capability branch.
- Deployment: nginx serves the built app; server.ts tracked; exclusion at the Docker layer (`.dockerignore` 48–49).

## 4. Standing rules (mirrored in EXPECTED.md / agent definitions)

- Provenance: establish any artefact's commit against HEAD before reading a number from it. A test artefact against a partly-changed build is a weaker witness.
- No figure for a population you haven't opened. Surface-not-store; state-not-transition; mount above EVERY gate. Gates derive from the store.
- **A spec may not feed itself the artefact under test** (trap 33). Expected values are hand-written literals, never computed with the function under test (trap 71's catch depended on it).
- **A probe that MODELS the path under test inherits the modeller's assumptions — drive the real path.** Round-trip checks drive the WRITER. Refusing a modelled probe and recording the limit open is the correct outcome when the real path is unreachable (the compounding rider, 2026-08-17).
- **Running a spec is evidence for what it mounts, nothing wider** — every certificate names the mounted/source-read boundary.
- An enumeration method is evidence about what it found, never what it missed. regression-guard classifies introduced vs pre-existing. A spec guard is verified by a planted violation or not verified; plants go where the heuristic is weakest; INCONCLUSIVE earns its keep (trap 15, 2026-08-18).
- Removal test authoritative when typecheck is green. Untestable-in-place code is itself the defect — extract the seam. **Third-instance rule:** load-bearing invariants are exercised at the site.
- JSON.stringify launders NaN to null; an exported 0 is not recoverable as absence. An absent pool is not an empty pool.
- Deployment "not needed" translates to a layer before deletion. A marker is not always evidence of the thing: the 'All' marker-meaning family now has FIVE sites (legacy import, retirement rule, mirror control, generate-button predicate, and `Is_Active`'s leaf-only lookup) — DQ's single source of truth closes them against one set.
- Duplicate predicates collapse on sight; one exported definition per concept, read by every consumer (orphans, block reasons, scope matching, summarisers).
- Reserved decisions stay reserved; sessions HOLD and present options. A decision recorded conditional on a measurement carries the measurement's verdict beside it — including a refutation.
- A harness noop is a declared gap needing a source-side count guard. Nullable-under-no-strict enumerates nothing.
- A check whose assertion doesn't mention what the function is FOR is not a check of it; traps are planted on FIXES.
- When a brief says "per <convention>", the convention wins over the brief's phrasing.
- **A check that cannot fail is worse than an absent one** (2026-08-13): style assertions pin a token existing ONLY in the asserted state, paired with a negative.
- **A source-text anchor is invalidated by DUPLICATION as much as by rewrite** (2026-08-13): anchors on shared idioms assert COUNTS, not presence — and a count is exact, never `>=` (a floor stops noticing disappearances; 2026-08-18). When a count legitimately moves, re-aim to the new number with the sites named.
- **A multi-part mutation whose cheap part succeeds reports PLANTED while the part that matters no-ops** (2026-08-13): verify each part landed, or split.
- **Anchors must not pin properties they are not testing** (2026-08-13): line endings normalised away.
- **NEW (2026-08-18) — a character-distance window is a proxy coupled to unrelated nearby text:** two such windows (600 and 1600 chars) broke in one arc against correct code. Anchor windows are bounded STRUCTURALLY — to a following branch, block, or named boundary — never by a count of characters. A proxy that works today and nobody can see will fail, or stop firing, for reasons unrelated to what it tests.
- **A summariser/projection describes, never re-derives** (2026-08-14): a display surface that recomputes an outcome is a new home for the semantics and will drift.
- **Measure before shipping a cost into a render path** (2026-08-17/18): state the threshold and why; the fallback is pre-authorised in the brief; a failed measurement is the session's deliverable. Timing figures name their conditions (Node under tsx bounds the arithmetic, not the paint).
